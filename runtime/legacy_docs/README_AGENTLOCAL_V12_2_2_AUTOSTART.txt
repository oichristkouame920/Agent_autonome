AgentLocal V12.2.2 - Démarrage Windows autonome

Nouveautés :
- démarrage discret à l'ouverture de session Windows, sans droits administrateur ;
- AgentLocal reste en arrière-plan jusqu'au premier déverrouillage utile ;
- routine matinale 07:00-09:30 conservée ;
- instance GUI unique : relancer AgentLocal ramène la fenêtre existante ;
- alertes avertissement/critique visibles même lorsque la fenêtre principale est cachée ;
- activation/désactivation depuis Paramètres ;
- préférence utilisateur persistante dans memory/windows_startup_preference.json ;
- aucun shell utilisateur ajouté et aucune action destructive automatique.

Le démarrage automatique est activé par défaut à la première installation V12.2.2. Si l'utilisateur le désactive depuis l'interface, les mises à jour suivantes respectent ce choix.
